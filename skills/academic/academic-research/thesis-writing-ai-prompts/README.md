# 毕业论文 AI 辅助写作提示词库

使用 DeepSeek / Claude / ChatGPT 等大模型辅助毕业论文、SCI / IEEE 论文写作的 50 个高阶提示词指令库，覆盖论文写作全流程。

## 使用场景

- 毕业论文 / 学位论文写作辅助（选题、文献综述、研究方法、结构设计、内容撰写）
- 学术语言润色与降 AI 率
- 数据分析与结果呈现
- 论文修改、审稿意见应对与模拟答辩
- SCI / IEEE 会议论文摘要与正文撰写

## 核心内容

- **50 个高阶提示词**，按写作流程分十大类：选题与方向、文献综述、研究方法、论文结构与逻辑、论文内容撰写、学术规范与语言润色、研究创新与深度、数据分析与呈现、论文修改与完善、论文写作辅助工具
- **降 AI 率人设提示词**：完整的角色扮演指令（Role / Background / Profile / Skills / Goals / OutputFormat / Workflow / Examples / Initialization）
- **专业硕士学位论文通用写作规范**：前置部分构成、摘要与关键词、目录与清单、正文格式通用原则、图表规范、参考文献格式（GB/T 7714）、附录与成果页
- **论文类型与审稿评审要点**：应用研究型定位、专题研究类 / 案例研究类、审稿评审检查清单、审稿指令示例
- 方括号 `[ ]` 占位符可直接替换为论文具体情况
