# 科研设备采购方法论

科研硬件设备（机器人、仪器、实验设备、传感器、工作站电脑等）采购的完整方法论——多厂商比价、背对背竞价、真实性验证、压价谈判、成交锁单、验收闭环。

## 使用场景

- 市场上有**多家供应商**可供货，存在比价空间
- 采购决策方（学校老师/企业领导）与**实际对接人（技术人员）分离**，你是中间桥梁
- 需要验证**产品真实性**（开源项目/自研产品的克隆、缩水版风险高）
- 目标：**项目最完善 + 价格最低**，让供应商互相竞争

## 核心内容

- **六步流程**：规格统一(RFQ) → 全市场厂商摸底 → 统一询价(双价策略+锁税口径) → 真实性验证 → 压价谈判(交叉比价+红白脸战术) → 定标下单与验收
- **法律与伦理红线**：只传真实报价、不虚构"另一家价"、如实报开票需求、守约付款
- **角色分工**：技术人员 = 中间桥梁（验真/比价/推荐/压价/成交锁单），财务流程决策归决策方
- **实战案例一**（双臂机械臂采购）：
  - 电商裸机价 vs 全套采购价陷阱（某协作臂：电商价 vs 中标价差数倍）
  - 力控架构辨析（关节力控 vs 末端六维力）
  - 开源生态作为验真与加分手段（GitHub star、实验室使用记录）
- **实战案例二**（GPU 工作站采购，整机/标准化硬件）：
  - 同一供应商报多套配置 → 用自家报价单互相印证挑水分
  - "成本价"信息泄露 → 绝不明说，只做内部底线
  - 红白脸双人战术
  - 售后地理/服务成本作为合法的"贵一点"理由
  - 税口径锁定（含税/税前做文章）
  - "选哪家都可以"是姿态放软的信号
  - 行情波动导致锁价失效时的双线并行
