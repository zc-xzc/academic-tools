# 科研设备/硬件采购方法论

> 面向科研场景的硬件采购实战方法论。适用于多供应商比价、背对背竞价、技术选型验证、压价谈判、成交锁单等场景。本文为方法论通用版，不含任何具体单位、人员与交易信息。

## 何时使用

当需要采购科研硬件设备（机器人、仪器、实验设备、传感器、工作站电脑等），且符合以下任一特征时：

- 市场上有**多家供应商**可供货，存在比价空间
- 采购决策方（如学校老师、企业领导、单位负责人）与**实际对接人（技术人员）分离**，你是中间桥梁
- 需要验证**产品真实性**（开源项目/自研产品的克隆、缩水版风险高）
- 目标：**项目最完善 + 价格最低**，让供应商互相竞争

## 核心原则

1. **背对背竞价**：让厂商互相竞争压价，但对接人**永远不点名对方身份**，只传递"另一家供应商报价/条件"。**真实的信息差**（获取多家真实报价并比较）是谈判优势。两家串通抬价的概率比互相压价大，所以**别把两家拉进同一个群**。⚠️ 只能传递**真实报价**，不得虚构"另一家报价"（见法律红线）。
2. **验证优先于价格**：先验证"产品是不是真货、能不能兼容你的生态"，再谈价格。低价克隆品往往比高价正品更贵（售后、返工、锁死生态的隐性成本）。
3. **规格统一（RFQ）**：让所有厂商按**同一套规格清单**报价，防止各说各话、无法横向比。
4. **书面化一切**：口头价不作数。所有价格、配置、交期、质保、发票形式必须落成**正式报价单/盖章合同**。
5. **决策权归位**：技术人员做技术判断（验真、比价、推荐、压价），但**财务/采购决策（开票方式、付款方式、采购抬头、预算上限、交付验收）由决策方拍板**，不要替决策方做决定，也不要过早向供应商暴露这些信息。

## 法律与伦理红线（不可逾越）

**背对背竞价是合法的，但必须建立在真实信息之上。以下行为严禁：**

1. **严禁虚构报价**：只能传递**真实存在**的其他供应商报价。**不得捏造"另一家报价"**（如编造一个不存在的低价）——这属于欺诈性误导，违反《民法典》诚实信用原则，情节严重的可能构成《反不正当竞争法》下的商业诋毁或民事欺诈。
2. **发票需求必须如实**：双价询价的前提是**采购方确实未确定报销形式**。若已明确只需普票，不得再以"可能需要专票"诱导供应商报价——这是虚假陈述。
3. **不串通、不恶意**：不参与供应商之间的价格串通；不以"不采购"为要挟索取不当利益。
4. **守约付款**：验收合格后应在合同约定期限内付款，不得以"验收"为名恶意拖延或压款。
5. **遵守采购法规**：若使用财政资金/属于政府采购范围，必须遵守《政府采购法》及单位内部采购制度（比价、招标、审批等法定程序），不得规避。
6. **信息披露边界**：拒绝透露其他供应商身份/报价来源是合法谈判策略；但**不得编造信息**。供应商直接询问时，可明确回应"不便透露"，不可虚构。
7. **书面合规**：所有合同条款（价格、交期、质保、发票、付款）真实可执行，不签署虚假合同。

> 一句话底线：**真实信息、正当竞争、诚实信用。** 让供应商真实地竞争，而不是用虚构的信息操纵他们。

## 促成话术核查（"送数据/送服务"类承诺）

供应商常用"赠送"来促成决策——如"送XX小时训练数据""送技术支持""帮你们快速启动"。**赠送是谈判桌上的加分项，不是决策依据**。任何"赠送"都要核查四件事：

1. **格式/可用性**：送的东西能不能直接用于你的工作流？如训练数据——是你要的格式、能直接喂训练，还是需要自己转格式/清洗？格式不兼容 = 0 价值
2. **任务匹配**：送的内容跟你的实际任务匹配吗？如数据是抓取/操作/还是别的任务，跟你要做的匹配吗？
3. **授权/来源**：能不能商用？**如果只是转手公开数据集（如开源数据集），等于没送**——那本来就是免费公开的
4. **要样本**：空口说"送XX小时"不核验。先要**格式说明 + 一段真实样例**（能下载试跑的那种），验证是真货再当谈判筹码

**关键**：把"赠送"的验证结果反馈给谈判——如果赠品是公开数据转手，直接点破并把它从价格里剔除；如果是真货，作为"价格包含的价值"而非"额外让利"来谈。

## 开源项目背书鉴别（供应商甩 GitHub 仓库时）

供应商用开源项目证明"我们家硬件有生态/好适配"时，**分清"真适配" vs "借名背书"**：

- **看它是不是真的跑你家硬件**：开源项目是否明确适配该厂商的型号、有真机验证、提供该硬件的采集/训练/推理脚本
- **借名背书的典型**：供应商甩一个知名团队/大厂的开源模型或平台，但那个项目跑的是别的硬件平台（如通用机器人数据集、仿真平台），跟该厂商硬件基本无关——这是借名气抬身价
- **真适配的证据**：项目里有该硬件型号的专用适配（如"XX臂 + 开源框架"的完整流程）、全流程真机验证、明确列出的硬件配置表

**判断标准**：供应商甩的开源项目，能否**直接在你的目标硬件上跑通采集→训练→推理**。能 = 生态证据，值钱；不能（只是同名/泛化平台） = 营销背书，不算数。

## 完整流程（六步）

### 第一步：规格统一（RFQ）

把模糊的采购需求变成可比清单：

- **产品形态**：穿戴式/背包式/桌面式/整机工作站等
- **关键规格**：CPU 型号、GPU 型号/显存、内存容量/频率、主板芯片组、电源功率、接口类型
- **交付要求**：是否含调试、是否开箱即用、SDK/源码/协议文档是否随货开放
- **商务条款**：发票类型、是否含运费、交期、质保、付款方式
- **数量与阶梯价**：首单数量 + 后续上量的阶梯政策

### 第二步：全市场厂商摸底

1. **找官方渠道**：官网、官方文档、官方认证厂商列表——这是"正规军"参照系。官方列表通常会标注厂商的认证状态（认证/评估中/未评级）和公开报价。
2. **收集所有已知厂商**：名称、所在地、官方状态、官方报价、联系方式。
3. **建立追踪表**：报价、规格、交期、质保、联系方式、询价状态、备注/结论。
4. **提前排除**：
   - 跨境厂商（开票、物流、售后麻烦，除非价格有压倒性优势）
   - 无对应产品（只有替代方案）
   - 无法对公开票（只能走个人账户，学校/企业对公流程走不了）

### 第三步：统一询价（双价策略）

- 每家发**同样内容**，保证横向可比。
- **双价策略**：同时问"含增值税专票"和"不需要专票（普票/收据即可）"两个价——发票形式是**价格变量**，不是固定项。报销口径未定时，用双价询价保持灵活性，不承诺也不要票。⚠️ 仅当**报销形式确实未定**时使用；若已明确开票类型，如实告知，不得用虚假的"可能需要专票"诱导报价（见法律红线）。
- 必问清单：是否有货、报价（人民币含运到手价）、核心规格、接口/驱动/SDK/中间件、是否兼容官方协议、真机照片/视频、交期、质保、阶梯价、是否可对公/电商平台下单。
- **锁税口径**：开口就问清楚"这个数是含税还是税前？税率多少？"——供应商口头报价常是税前价，不锁定口径，收口时他会在税上找补。统一按**含税总价**谈。

### 第四步：验证产品真实性（试金石）

对照**官方公开规格**逐项问，这是判断真货/克隆的核心：

- 核心部件**具体型号/数量/位数**（如 GPU 全新还是改造卡、编码器品牌型号）
- **接口类型**、协议文档
- **软件兼容性**：能否直接跑官方代码/驱动，还是必须用供应商自研驱动

**关键判断**："是XX产品"≠"达标的XX产品"。供应商口头承认产品名，不代表规格达标。

**红旗信号**（任一命中即警惕）：
- 报不出核心部件型号/规格，或说"太细节说不清"、"自己拆开看"
- 拒绝提供参数文档/协议文档/SDK → 无验收依据
- 必须绑定自家驱动/生态 → 官方不兼容风险
- 用"已销售XX台""大客户在用""工程师都买"等**营销话术代替技术规格**
- 连产品手册都没有 / 对自家产品参数不熟（要"问同事"）

**要求**：书面规格书、真机视频（最好含**数据流画面**）、SDK/协议文档随货承诺。

### 第五步：压价谈判（交叉比价）

- 用 A 的价压 B，用 B 的价压 A，循环两轮。
- 永远说"另一家供应商"，**不点名**。
- 用真实参照锚定价格：
  - **官方认证渠道报价**（正规军价）
  - **电商平台价**（标准化硬件如整机电脑、SSD、内存，电商价是最有力的锚）
  - **不含税底价**（含税价÷1.13，看真实成本线）
  - **套件价 vs 单卖价拆解**（套件里隐含单价 vs 口头单价，找出虚标）
- 压价理由："企业/学校采购"、"内部预算上限"（客观约束而非攻击）。⚠️ **"后续上量"只能在你确有批量计划时提及**，否则属于虚假陈述（见法律红线）。
- **发票是压价空间**：专票→普票→不要票，逐级可降（税负成本传递）。
- **别一次亮全部底线**，别把预算上限和成本拆解一次甩光（会砍光对方利润想象空间、激起逆反）。给台阶，留余量。
- **红白脸双人战术**（见实战案例）比单人单刀压价更有效。

### 第六步：定标下单与验收

- 设截止时间（如"本周X前给最终价，价优方案全者得"），到点不再拉扯。
- **付款方式协商**：供应商常要求"预付全款"，采购方要"货到验收后付款"。**担保交易平台（电商平台托管）是双赢解法**——下单付款进平台托管，供应商发货，采购方验收后确认收货才放款。两边需求都满足，且有第三方担保。⚠️ 若交付/支付由决策方负责，技术人员只需在成交时把"具体型号、成色、序列号、全新承诺"锁进正式报价单，不越界谈付款。
- **成交锁单**：价格谈定后，让供应商**重新出一版正式报价单**，把谈定的每一项（具体型号、含税总价、成色、序列号随货承诺）白纸黑字写下——口头降的价必须体现在报价单上，否则回头报价单里找补回来。
- **验收清单**（全过才确认收货放款）：
  1. 商品参数单**逐项核对**（型号/数量/结构/接口）
  2. 拆箱前后**照片留证**
  3. 发票：抬头/税号/类型（专票/普票）核对
  4. **实际测试**：能否跑官方代码/协议；整机跑 30 分钟烤机看温度/稳定性
  5. 全部通过 → 确认收货 → 货款放给供应商

## 角色分工（技术人员 = 中间桥梁）

```
采购决策方（学校/企业/单位）      技术人员（你）              供应商
  开票方式 │                    │ 询价/比价/压价          │
  付款方式 │ ←—— 确认口径 ——→   │ ——→ 统一询价 ——→        │
  采购抬头 │                    │ ←—— 报价/规格 ——→       │
  预算上限 │                    │ 验真/核参/把关            │
```

- **技术职责**：验真、比价、推荐、话术执行、压价、成交锁单。
- **关键纪律**：
  - **先问决策方开票口径和付款方式，再定报价口径**——不要替决策方决定，也别向供应商暴露。
  - 向决策方汇报时：技术结论你给出，财务/流程决策留给决策方。
  - **职责边界明确时别越界**：若交付/支付/验收由决策方或他人负责，你的活儿就是压价 + 把条款锁进报价单，不谈付款方式、不承诺验收口径。
  - "不需要专票能再便宜"是向决策方如实说明的报价差异点，便于其决策。

## 决策矩阵打分框架

| 维度 | 说明 | 评分 |
|---|---|---|
| 真实性 | 能否报出官方规格、有无书面文档/真机视频 | 1-5 |
| 兼容性 | 能否跑官方代码、协议是否开放 | 1-5 |
| 价格竞争力 | 含税含运到手价横向比较 | 1-5 |
| 交期 | 下单到货时间 | 1-5 |
| 售后/发票 | 质保、技术支持、售后便利度、开票合规 | 1-5 |

- 综合分 = 五项加权和。
- **典型决策线**：官方认证（贵但硬） vs 低价待验证（便宜但风险）——根据价差定取舍。价差小于某阈值选认证硬，大于阈值选性价比。
- **售后便利是真实价值**：本地/近处供应商售后上门快、扯皮少，为这个多花 ¥500-1,000 是合理的选型溢价——算的是总拥有成本（含售后隐性成本），不是裸价。

## 避坑清单

1. 口头价不作数，全部落书面报价单/合同。
2. 配件别漏算（控制器/电源/线材/包装，可能单独加价）。
3. 功能需求分清"必需"和"加分项"——把加分项当压价理由，别当废标理由。
4. 兼容性/接口开放性写进合同，防被锁死生态。
5. 付款争取货到验收或担保交易，别全款预付；至少留质保金。
6. 交付物清单（源码包/SDK/接口文档/说明书）逐一列进合同。
7. 供应商"官方合作/认证"措辞要核实（官网认证状态为准，别听自称）。
8. "送数据/送服务"等促成话术要核查格式/授权/来源，公开数据转手 = 没送，别被数字晃到。
9. 供应商甩开源项目背书时，鉴别是"真适配你家硬件"还是"借名背书"，别被大牌名字晃到。
10. 验收时核对"到手装配完整、无缺件"——有厂商到手缺件、以"运输脱落"推诿的教训。
11. 供应商"开箱即出XX格式/即用"类承诺，要实测样例验证，不口头信。
12. 询价后供应商冷处理/不回消息 ≠ 谈崩：用"我们在对比别家"（基于事实）+ 决策时限逼他动，别反复催。
13. 同一供应商报多套配置时，用**自家报价单互相印证**挑水分；但目标方案里已是实价的项别硬砍。
14. 成本价信息（误发/转述）**绝不明说**，只作内部底线；公开压价只用"另一家真实报价"。
15. 多人采购用**红白脸战术**：白脸压价、红脸给台阶+长期合作预期，配合收口。
16. 压价前锁定"含税总价"单一口径，防供应商在税前/含税上找补。
17. 成交后让供应商**重出正式报价单**锁型号/成色/序列号/含税总价，口头降的价必须落在纸面。
18. **行情波动风险**：价格锁定后供应商可能以"上游涨价"要求重谈（尤其显卡等禁售/限购件）。处理：理解 + 坚持锁定总价 + 要求"有变动提前说"，同时用另一条真实报价线做备胎施压。

## 模板库

### 通用询价模板

> 你好，我们是[高校/企业]采购，想采购[产品]。确认几个问题：
> 1. 你们有[产品]吗？报价多少？人民币结算含运到手价？**这个数是含税还是税前、税率多少？**
> 2. 能报两个价吗——含13%增值税专票 和 不需要专票（普票/收据）各多少？我们报销形式还没最终定。
> 3. 核心规格：[部件]型号/数量？[关键参数]？
> 4. 输出接口：CAN还是USB？驱动和SDK随货吗？源码开放吗？能否兼容官方协议？
> 5. 有真机照片/视频吗？交期多久？质保多久？调通/技术支持收费吗？
> 6. 我们后面可能上量，多套有阶梯价吗？
> 麻烦发正式报价单（含配置明细、税点、交期、质保）。谢谢！

### 压价话术（拿A压B）

> 另一家供应商[类似条件]，[报价/条件]。你们这个价没有优势。我们是企业/学校采购，后面有上量计划。给个实价，能到位今天就定，不能我们走那边。

⚠️ **必须使用真实存在的报价**。如果只是"听说有更便宜的"而说不出真实来源，就不要提；虚构报价属于欺诈，详见法律红线。

### 红白脸双人战术收口语术

白脸先压（强硬挑单项、砍总价，摆出"这单可做可不做"），红脸再收：

> 白脸："这台 [主要件] 比电商贵一截，机箱这种件 200 多的够用了，内存也报得偏高。总价还有空间。"
> 红脸："我们综合下来倾向您这边——[就近/售后方便/走采购流程]，[关键件升级] 我们也认可。含税总价抹个零 **¥[目标价]**，今天付定金走流程，后面[真实上量需求] 优先从您这边走。行的话出最终配置单，我们直接下单。"

### 最终报价定标话术

> 我们最终候选名单里有两家，谁的方案最全、价格最低、交期最快，单子给谁。请各自给最终含税价（含运费、含发票），[截止时间]前回复，过时不候。

### 付款冲突化解（预付 vs 货到验收）

> 我们采购流程是货到验收后付款。走电商平台担保交易正好解决——我们下单付款后钱在平台托管，你们发货、我们验收没问题再确认，两边都放心。

### 供应商冷处理跟进（不回消息）

> 您好，之前问的几个问题有空帮忙确认下（[具体问题列表]）。另外我们在对比几家方案（[如实列出的其他候选]），如果这边能出正式报价单，我们尽快评估。这周能定下来的话，我们往下走流程。

### 供应商持续不回（给决策时限）

> 我们采购时间比较紧，如果这周给不了报价单，我们先推进别家。等您的报价单到了我们再评估，保持联系。

### 成交锁单话术（价格谈定后发）

> 收到，[含税总价 ¥X] 确认。麻烦重新出一版正式报价单：含税总价、[关键件具体型号]、[成色/全新]、[序列号随货] 都写上，我们核对无误就走流程。

### 行情波动涨价应对话术

> [供应商]的价格已锁定，我们按锁定总价走。上游涨价我们理解，但请按谈定的总价执行；若确有变动，提前跟我们说一声商量——但总价我们希望不变。

### 验收清单话术

> 商品参数单 + 到货后产品照片 + 发票，三样齐全后打款。到货时请核对参数单逐项验收，测通官方代码再确认收货。

## 实战案例一：双臂机械臂采购

真实采购经历提炼的经验，适用于任何"多厂商竞争的高端科研硬件"采购。

### 1. 电商裸机价 ≠ 全套采购价（最大的价格陷阱）

同一型号，电商标价和正式采购价可能差数倍。以某 5kg/6轴 协作臂型号为例：

| 渠道 | 价格 | 说明 |
|---|---|---|
| 电商裸机价 | ¥12,800–36,000 | 不含控制柜、示教器、软件授权、调试、质保、税 |
| 高校中标价 | ¥80,000/台 | 含全套配置 |

**应对**：询价时**必须要求逐项拆列**（裸臂/控制器/示教器/软件/夹爪/支架/税），别被电商裸机价误导，也别让全套价虚高。电商裸价可以用来当压价锚——"你们电商才标X，含全套为什么Y？逐项列出来。"

### 2. 力控架构辨析：关节力控 vs 末端六维力（技术选型核心）

机器人"力控"不是一回事，采购前必须分清，否则可能买到不满足研究需求的硬件：

| | 关节力控 | 末端六维力 |
|---|---|---|
| 传感器位置 | 每个关节内置力/力矩传感 | 只在末端法兰装六维力传感器 |
| 感知能力 | 知道哪个关节受力、全身状态 | 只能感知末端受力 |
| 碰撞反应 | 碰撞自动降关节刚度、全身卸力 | 末端检测到力，关节无法单独卸力 |
| 可实现 | 全身柔顺装配、人机协作、复杂接触 | 末端力跟踪、简单插拔/打磨 |

**关键判断**：
- 研究需要"全身柔顺/碰撞安全/复杂接触"→ 必须关节力控
- 只需要"末端力觉"→ 末端六维力够用，性价比高
- **末端六维力可以后加在关节力控臂上（选配），但关节力控无法靠末端传感器升级**——预算允许时关节力控更"向上兼容"
- 厂商宣传要核实：某厂商官网原文"法兰末端内置六维力传感器"（末端）；另一家"7DoF×2标配关节力控"（关节）。**别被"力控"两个字混过去**

### 3. 开源生态作为采购验真与加分手段

高端科研硬件（尤其机械臂）有没有开源生态，是判断"值不值"和"是否真货"的强信号：

- **查GitHub**：官方仓库（驱动/SDK/ROS集成）、社区star数、活跃度
- **查论文/实验室使用记录**：知名实验室用没用、有没有公开使用笔记
- **开源生态的价值**：①证明产品被真实科研社区使用（不是小众自研）②降低上手成本（现成示例/驱动/训练流程）③厂商送的开源配套能省数月工作量
- 谈判筹码："你们有XX开源项目、送XX数据"→ 可换算成价格价值或要求配套

### 4. 力控精度参数要具体

问力控不能只问"有没有力控"，要问：
- 传感器在哪（关节/末端）？几个？量程？精度？
- 力控采样/控制频率？作用力重复精度？
- 控制协议、ROS支持、SDK开放度
- 末端六维力是否选配、加多少钱

> 教训：供应商说"我们有六维力"和"我们关节力控"，可能差一个技术档次。拿到参数表核对，别信口头概括。

## 实战案例二：GPU 工作站采购（整机/标准化硬件）

真实案例提炼，适用于整机/DIY 电脑等标准化硬件的采购压价。多供应商竞价 + 同一供应商多方案 + 红白脸多人配合，最终从含税总价压掉约 3%。

### 1. 同一供应商报多套配置 → 用"自家报价单互相印证"挑水分

当一家店同时报两套方案（如 Intel 平台 + AMD 平台），不要只看总价，**把两套方案的同类型件横着比**：

- 例：方案A 配某二线内存 6400 报 ¥3,800/条，方案B 配某原厂内存 5600 报 ¥2,895/条——**二线品牌比原厂条还贵 ¥900/条**，这就是虚高的铁证。
- 供应商自己的两份报价互相打脸，比拿电商价压更硬（他没法说"你那是别的渠道"）。
- **但要分清战场**：当目标方案里对应件已是实价（如方案B 的该原厂内存就是行情价），就别再拿另一方案的虚高去砍——那是那套方案的毛病，砍不到目标方案头上。挑水分要挑**目标方案里确实偏高的项**（SSD、机械盘、机箱这类价格透明的），有依据才砍。

### 2. "成本价"信息泄露 → 绝不明说，只做内部底线

中间人意外拿到供应商成本价（误发/转述）时：

- **红线**：绝不对供应商说"我知道你成本"——一出口就出卖了信息源，中间人关系全毁，且以后对方永远不给实价。
- **正确用法**：①做心理底线（成本 + 合理毛利 ≈ 接受上限）②验证单项水分（对照成本看报价项虚不虚）③压价时用"另一家正式报价"当公开武器，不是成本价。
- 成本价还带出隐性信息：如"按成本价他都不给维护"→ 报价里那部分利润就是售后成本。**砍价目标不是砍到成本，是让他保留合理利润**——砍到没利润，他售后也敷衍。

### 3. 红白脸双人战术

多人采购时分工配合，比单人单刀更有效：

- **白脸**（如采购协调人）：强硬挑刺、砍单项（"机箱电脑城 200 块""SSD 比电商贵""内存太贵"）、压总价，把"这单可做可不做"的态度摆出来。
- **红脸**（如技术人员）：打技术牌、认可对方优点（"售后方便""水冷/风冷方案好"）、给台阶（"后续还有采购""算力需求大"）、收口。
- 效果：供应商被白脸压到接近底线后，红脸的认可 + 长期合作预期让他在"少赚一点但保住长期客户"上成交。
- **关键**：红脸的话术必须真实（后续需求是真的），白脸压的每一项都有依据（电商价是真的）——否则一戳就穿。

### 4. 售后地理/服务成本是合法的"贵一点"理由

- 本地/近处供应商：售后上门快、扯皮少 → 为这个多花 ¥500-1,000 是合理的选型溢价。
- 异地供应商：光车票就几百块 → 售后隐性成本高，价差不足以覆盖就别选。
- 案例里"本地近、异地车票两三百"直接决定选型：本地供应商多报 ¥350 仍被选中，因为省下的潜在售后成本远超 ¥350。
- 这是"低价≠总成本低"的典型：把售后便利换算成钱，算的是总拥有成本，不是裸价。

### 5. 税口径锁定（含税/税前做文章）

- 供应商口头报价常是税前价（报价单"小计"不含税），他说"¥43,500"你不问就含税成交，到手变 ¥44,000+。
- **压价前先锁定单一口径**："我们按含税总价谈"——让他把含税总价、税率、税金写进报价单。
- 收口时目标价（如"¥42,000 含税"）必须说成含税总价，防止他在税上找补。
- 案例里锁定"含税口径"后，供应商从含税 ¥44,197.6 让到 ¥43,000（含税），真实让了 ¥1,197；如果不锁口径，他口头 ¥43,500 可能是税前，含税实付 ¥43,935。

### 6. "选哪家都可以"是姿态放软的信号

供应商说"选哪家都可以"、"成本确实高" = **价格咬死，但把决定权交给你**，暗示他认了价差、赌你权衡后会回来。此时：

- 别立刻松口降价，也别连发追问——他可能正在跟老板批价。
- 给时间窗（半天到一天），用冷处理应对（见避坑清单）。
- 用"另一家正式报价还压着 + 我们两天内要定"逼他，而不是自己让步。
- 他冷处理后主动回来给价，说明这单他想要，此时按你的锚接住即可。

### 7. 行情波动导致锁价失效时的双线并行

价格锁定后，供应商以"上游涨价"为由要求重谈（显卡等禁售/限购件常见）：

- **理解但不松口**：认可行情是真实的，但强调总价已双方确认（聊天记录即证据），要求按锁定价走。
- **让供应商自己消化**：说"我再找找便宜的"= 他还在努力找货消化价差，给他时间和压力，别立刻让步。
- **双线并行**：同时维护另一条真实备选线，让两家互相施压。谁先按目标价到位谁接单——你永远握选择权。
- **备选线条件要提前钉齐**（含税口径、全新/序列号、散热方案、交付），避免临时切换时手忙脚乱。
- 切换供应商的成本（重新走流程、交付延迟）要算进决策，价差不大时优先稳定供应商。
