# 课题组申请与面试通用规范

研究生/博士/科研助理/访问学生/实习申请人联系课题组前后的通用方法论——调研 → 材料 → 面试 → 复盘 → 跟进 → 试做的完整闭环。通用版，不含任何具体课题组、人员、机构与产品信息。

## 使用场景

- 撰写**首封联系邮件（套磁）**或询问招生名额
- 准备**预筛/组内交流/正式面试**的材料（简历、PPT、一页研究想法、论文笔记、跟进话术）
- 被**追问项目细节**、问短板、问试做意愿，需要应答框架
- 面试后需要**复盘分级、写跟进邮件、决定是否接受试做**
- 申请未推进，需要**原因归类与长期补强计划**

## 核心内容

- **核心原则**：少而清楚、贡献可验证、调研到论文层、问题可落地、短板不回避、跟进有节制
- **面试前准备**：课题组五层拆解（方向/论文/平台/缺口/匹配）、代表论文阅读模板、简历/PPT/一页想法/论文笔记最小组合
- **PPT 结构规范**：11 页默认结构（自我定位 → 能力结构 → 两个代表项目 → 对目标组的理解 → 可试做切入点 → 短板补足 → 开放问题）
- **项目表达六句式**：问题 / 角色 / 方法 / 难点 / 结果 / 迁移，90 秒讲完
- **面试中表达规范**：被追问回答公式（项目真实性/创新点/选组理由/短板/试做/交接）+ 禁用表达对照
- **面试后复盘**：信号提取 → 结果分级（A 强推进 / B 可试做 / C 中性待定 / D 不匹配）→ 材料修正 → 24h 跟进
- **跟进模板**：预筛后中性偏正向 / 正式面试后补材料 / 暂不推进后维护
- **试做任务边界确认表**：目标、输入、交付物、时间节点、协作对象、边界风险、长期连接
- **长期改进路线**：1 周到 6-12 个月的可执行清单
- **附录**：首封联系（套磁）通用结构与节奏、可向对方提问的通用清单
