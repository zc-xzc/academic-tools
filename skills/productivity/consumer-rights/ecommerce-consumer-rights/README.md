# 电商购物维权方法论

基于真实淘宝发票纠纷案例提炼的电商购物维权方法论——覆盖发票迟迟不开、退款被拒、客服推诿、平台规则死循环等高频场景。

## 使用场景

- 商家迟迟不开具发票，客服反复拖延
- 退款被拒，商家只愿退小额"补偿款"或给红包
- 客服反复踢皮球，让你联系第三方或用套话打发
- 平台规则死循环（开票要等售后结束 → 售后要退货 → 商品已使用无法退）
- 官方店/自营店也不处理，商家与平台互相推卸

## 核心内容

- **维权铁律**：证据固定、明确诉求、书面化、不随意撤销申请
- **维权路径升级图**：商家客服 → 平台在线客服 → 官方热线 → 投诉/举报 → 平台介入 → 外部监管（12315/12366）
- **客服话术识别与应对**：识别"非常理解您的心情""建议联系税务局"等推诿话术
- **各场景应对方案**：发票不开、退款被拒、商品已使用无法退货、官方店不处理
- **法律依据**：发票管理办法、消费者权益保护法、电子商务法
- **沟通模板库**：首次联系、施压、拒绝打发、要求升级、外部举报
