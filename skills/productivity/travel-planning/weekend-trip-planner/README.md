# 短途/周末/周边游规划助手

从聊天记录或直接请求中提取出行意图，核查目的地天气，用天气决策树输出一日游/两日露营方案。内置安徽合肥周边（六安屋脊山/横河岭/九公寨/庐江川藏线等）与青甘大环线知识库，含露营装备与预算模板。

## 使用场景

- 周末出游、周边自驾、小长假旅行、露营规划
- 拿到一段聊天记录后让助手"读一下帮我们安排行程"
- 需要结合目的地天气决定一日游还是露营

## 核心特点

- 天气决策树：根据预报自动调整行程方案
- 内置合肥周边与青甘大环线两个知识库
- 露营装备与预算模板
- 输出一律中性称呼，不包含个人隐私
