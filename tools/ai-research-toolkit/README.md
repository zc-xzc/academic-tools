# AI 科研工具链实用手册

> 面向科研人员的 AI 工具使用指南，聚焦「写综述、整理文献、处理数据、学术写作」四件事。
> 全部内容来自亲身实践 + 公开信息，不含任何个人或隐私信息，可安全公开。

---

## 为什么写这份手册

科研中最耗时的往往不是实验，而是文献、综述、数据整理和论文写作。AI 工具能大幅压缩这些时间，但难点在于"怎么选、怎么配、怎么用"。本手册解决这个问题：把一套经过验证的工具组合，按场景拆开讲清楚，并给出官网、注册方式、上手步骤和可直接套用的提示词。

## 核心推荐（三件套）

对大多数科研场景，先试这三样：

1. **DeepSeek** —— 免费主力，中文写作、综述、代码都够用（网页版 + API）
2. **磐石** —— 用学校 edu 邮箱注册，文献综述生成很强
3. **Codex 接 DeepSeek API** —— 2 分钟配置，写脚本处理数据，成本极低
