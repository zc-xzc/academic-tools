# 01 通用大模型

通用大模型用于对话、写作、问答、数据处理。本节按「用途 + 官网 + 注册 + 上手」介绍，并标注免费/付费。

---

## DeepSeek（最常用，强烈推荐）

- **官网**：网页版 `chat.deepseek.com`；App「DeepSeek」；API 平台 `platform.deepseek.com`
- **注册**：手机号即可，网页/App 直接注册
- **费用**：网页版免费；API 按量计费（详见下文）
- **用途**：写综述、改论文、写代码、处理数据、日常问答。中文效果好
- **上手**：
  1. 直接对话，支持上传文件（图片 / PDF / Word / Excel）。
  2. 写综述：输入主题 → "帮我写一篇关于XX的综述框架，先列大纲" → 逐段展开。
  3. 处理数据：上传 CSV/Excel → "帮我分析趋势并生成图表代码"。
- **API（进阶）**：
  - 在 `platform.deepseek.com` 注册并创建 API Key。
  - 按量计费，支持官方文档里的标准接口，可接入 Codex / VSCode / Trae 等（见 04 章）。
  - 2026 年已推出 V4 系列，包含峰谷定价与百万级上下文版本；部分 Pro 版本长期降价（具体以官方最新为准）。

---

## ChatGPT / GPT

- **官网**：`chat.openai.com`（需可访问国际网络）；App 同名
- **注册**：OpenAI 账号（手机/邮箱），基础版免费
- **费用**：免费版额度有限；Plus 订阅功能更强
- **用途**：英文润色、通用写作、PPT、复杂推理
- **上手**：
  - 英文润色：粘贴段落 → "帮我润色成学术英语"
  - 写 PPT：给主题 → "生成PPT大纲"

---

## 豆包（字节跳动）

- **官网**：App「豆包」；网页 `doubao.com`
- **注册**：手机号 / 抖音账号
- **费用**：免费
- **用途**：中文问答、总结视频内容、语音对话、口语练习
- **上手**：日常问答；让它总结抖音视频；用语音对话练英文口语

---

## Kimi（月之暗面）

- **官网**：`kimi.moonshot.cn`；App「Kimi」
- **注册**：手机号
- **费用**：免费（有一定免费额度）
- **用途**：长文本阅读（论文 / 长文档）
- **上手**：上传长论文 → "帮我总结核心观点"；可一次上传多个文件对比

---

## Claude（Anthropic）

- **官网**：`claude.ai`（需可访问国际网络）
- **注册**：邮箱 / Google 账号
- **费用**：免费版有额度；Pro 订阅
- **用途**：长上下文、论文精读、代码编写、复杂分析
- **上手**：上传 PDF 精读、提问；写代码、改代码能力强；Claude Code 可本地跑（见 04 章）

---

## Gemini（Google）

- **官网**：`gemini.google.com`（需可访问国际网络）
- **注册**：Google 账号
- **费用**：基础免费，进阶订阅
- **用途**：调用论文提取数据、建数据库、表格处理
- **上手**：上传 PDF → "帮我提取这篇论文里的化合物数据，整理成表格"；适合从文献批量抽结构化数据

## 千问 Qwen（阿里）

- **官网**：`tongyi.aliyun.com`；App「通义千问」
- **注册**：手机号 / 支付宝
- **费用**：免费
- **用途**：中文问答、长文本；通义听悟（音频/视频转文字、会议纪要）
- **上手**：通用问答；上传文档处理；用通义听悟转录会议录音

---

## NotebookLM（Google）

- **官网**：`notebooklm.google.com`（需可访问国际网络）
- **注册**：Google 账号
- **费用**：免费
- **用途**：把资料变成可提问的知识库（整理文献神器）
- **上手**：上传多个 PDF → 针对资料提问（"这些文献里关于XX的观点有哪些"）；自动生成摘要、时间线、FAQ
