# 02 科研专用工具

## 磐石（科学基础大模型）★★★

- **性质**：面向科研的国产科学大模型，写综述、查文献特别强
- **获取**：搜索「磐石 科学大模型」或通过学校/合作渠道获取入口；**必须用学校 edu 邮箱注册**
- **注册**：用 `@xxx.edu.cn` 学校邮箱注册，审核通过后登录
- **费用**：学校渠道通常免费
- **上手**：
  1. 用学校邮箱注册 → 等审核通过（一般 1-3 天）。
  2. 选择"文献综述"功能，输入主题 → 自动生成综述框架/内容。
  3. 与"文献罗盘"配合使用效果更好。
- **提示**：注册用普通邮箱可能审核慢或失败，优先用学校邮箱；也可通过科技云等渠道。

## 文献罗盘（ScienceOne S1-Literature）

- **性质**：中科院系 AI 科研助手，文献检索 + 综述辅助
- **官网**：`scienceone.cn`
- **注册**：用学校 edu 邮箱注册，审核通过后登录
- **费用**：免费（审核制）
- **上手**：注册 → 审核 → 登录 → 检索文献、辅助写综述
- **提示**：如果收不到审核邮件，试试清空浏览器记录或换浏览器；必要时联系客服邮箱。

## 玻尔学术 AI

- **性质**：学术文献检索工具，与高校有合作
- **获取**：搜索「玻尔学术」，用邀请码注册可领 VIP
- **上手**：注册 → 输邀请码 → 检索学术文献

## TCMSP（中药成分数据库）

- **性质**：中药活性成分数据库（做中药方向必需）
- **官网**：`tcmsp-e.com`（西北大学王永华团队开发）
- **费用**：免费
- **上手**：
  1. 输入中药名（如"黄芪"）→ 得到成分列表。
  2. 每个成分有分子式、分子量、CAS 号、靶点等。
  3. 可导出数据做进一步分析。
- **提示**：适合查化合物基础信息、做中药成分-靶点网络分析。

## 北大法宝 MCP

- **性质**：政策 / 法规检索接口，可接入 AI 使用
- **获取**：北大法宝官网申请 API/MCP（用学校邮箱）
- **上手**：申请接口 → 在 AI 工具（如 Trae / Codex）中添加 MCP 配置 → 让 AI 直接检索法规政策
- **提示**：免费额度有限，可多备几个邮箱申请。

## SCENIC

- **性质**：单细胞转录组基因调控网络推断（生物信息学）
- **获取**：开源工具，GitHub 搜索 SCENIC，Python 安装 `pip install pyscenic`
- **上手**：输入单细胞表达矩阵 → 推断基因调控网络
- **提示**：适合有单细胞数据的研究者，非中药/普通科研必装。
