# 03 文献管理与写作

## Zotero（文献管理）★★★

- **官网**：`zotero.org`（免费）
- **上手**：
  1. 下载安装 + 注册账号（跨设备同步）。
  2. 装浏览器插件（Zotero Connector），一键抓取网页文献信息（arXiv / 知网 / Web of Science 等）。
  3. 用文件夹/标签分类管理。
  4. 装 Word / Google Docs 插件，一键插入引用、自动生成参考文献。
  5. 配 Obsidian 插件 "Zotero Integration"，在笔记里直接引用文献。
- **提示**：与 EndNote 二选一即可，推荐 Zotero（免费 + 跨平台）。

## Obsidian（笔记 / 知识库）

- **官网**：`obsidian.md`（免费）
- **上手**：
  1. 创建仓库（Vault），用 Markdown 记笔记。
  2. 用双链 `[[笔记名]]` 关联知识。
  3. 装插件：Zotero Integration、Dataview、Templater。
  4. 经典组合：Zotero + Obsidian + Codex → 把论文变成可提问的科研知识库。
- **提示**：笔记存在本地，隐私安全；用同步插件可多设备。

## Overleaf / LaTeX（论文排版）

- **官网**：`overleaf.com`（免费账号即可）
- **上手**：
  1. 新建项目，选模板（期刊常提供官方模板）。
  2. 用 LaTeX 语法写作，支持实时预览、多人协作、版本历史。
  3. 不会 LaTeX？让 AI（DeepSeek / Claude）帮你写代码。
- **提示**：SCI 投稿常需要 LaTeX；也可用 Word 转。

## EndNote（文献引用）

- **官网**：学校图书馆通常有正版
- **上手**：从数据库导入文献 → Word 中插入引用 → 生成参考文献。
- **提示**：与 Zotero 二选一。

## Python（数据处理 + 绘图）

- **官网**：`python.org` 或 Anaconda
- **上手**：
  1. 安装 Python + Anaconda（自带 pandas / matplotlib / jupyter）。
  2. 用 pandas 处理数据、matplotlib 出图。
  3. 不会写？让 AI 生成代码（见 05 章提示词 #5 #6）。
  4. 通用流程：读数据 → 清洗 → 分析 → 出图。
- **提示**：Jupyter Notebook 适合逐步探索；数据量大可上服务器。

## 一个完整文献工作流

```
1. 检索文献（文献罗盘 / 学校数据库 / arXiv）
2. 用 Zotero 收集并分类
3. 用 NotebookLM 或 Obsidian 建知识库，逐篇总结
4. 用 Gemini 从关键论文提取结构化数据
5. 写综述时用 DeepSeek 生成框架 → 用自己的话填充
6. 用 Zotero 生成参考文献 → 用 LaTeX 排版
```
