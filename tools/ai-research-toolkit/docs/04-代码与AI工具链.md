# 04 代码与 AI 工具链

## Codex 接 DeepSeek（★★★ 省钱方案）

- **用途**：用 DeepSeek 驱动 Codex 写代码 / 处理数据，成本远低于直接订阅。
- **原理**：Codex 是 OpenAI 的 AI 编程工具，通过自定义 API 可切换到其他模型（如 DeepSeek）。
- **上手（约 2 分钟）**：
  1. 在 `platform.deepseek.com` 创建 DeepSeek API Key（充值少量）。
  2. 在 Codex 设置中选择"自定义 API"，填入 DeepSeek 的 API 地址。
  3. 填入你的 DeepSeek Key。
  4. 即可用 DeepSeek 驱动 Codex 写脚本、处理数据、搭工作流。
- **提示**：DeepSeek 2026 年有 V4 系列（峰谷定价、百万级上下文），按量计费，用多少付多少。

## TRAE（字节 AI 编程）

- **用途**：AI 辅助编程 / 工作流搭建，上手简单。
- **获取**：下载「Trae」客户端。
- **上手**：直接输入需求（"帮我写一个处理 Excel 的脚本"），或给一个 skill 名称让它自己安装使用。支持手机/电脑同步，可在手机发指令。

## GitHub / Git（代码托管 + 开源）

- **官网**：`github.com`
- **上手**：
  1. 注册账号，创建仓库（Repository）。
  2. 本地装 Git，`git init` → `git add .` → `git commit` → `git push`。
  3. 可公开（Public）或私有（Private）。
- **协作流程（main + 分支 + PR）**：
  1. 从 main 拉分支：`git checkout -b feature/xxx`
  2. 上传文件、提交、推送：`git push origin feature/xxx`
  3. 在 GitHub 创建 Pull Request（PR），审查后合入 main。
  4. 用 GitHub API 也可直接创建 PR（适合自动化）。
- **提示**：公开仓库前务必检查无隐私、无密钥。

## VSCode（代码编辑器）

- **官网**：`code.visualstudio.com`（免费）
- **上手**：
  1. 安装 VSCode。
  2. 装 AI 插件（如 Claude Code、Continue、通义灵码）。
  3. 在插件中配置 API（可接 DeepSeek）。
  4. 在编辑器里写代码、让 AI 补全 / 解释 / 改错。
- **常用快捷键**：`Ctrl+Shift+P` 命令面板、`Ctrl+` 打开终端。

## 一个最小工作流示例

```
任务：把一份 Excel 数据处理成图表
1. 用 DeepSeek 问："我想分析某列数据趋势，给一段 Python 代码"
2. 拿到代码，在 VSCode（或直接）运行
3. 数据多/反复跑 → 用 Codex 接 DeepSeek 搭个工作流
4. 代码有价值 → 整理进 GitHub 仓库，走 分支+PR
```
