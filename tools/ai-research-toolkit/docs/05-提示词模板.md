# 05 提示词模板

> 这些提示词可以直接复制使用，覆盖科研最常用的场景。括号里的内容替换成你自己的。

## 一、写综述 / 查文献

**1. 生成综述框架**
```
请帮我写一篇关于【研究主题】的中文综述框架，先列出一级/二级大纲（引言、方法、各研究方向的现状、挑战、展望），每部分给 2-3 个关键要点。要求结构清晰、逻辑完整。
```

**2. 总结一篇论文**
```
请用 300 字总结这篇论文：研究问题、方法、主要结果、局限、对我的启发。用中文。
```

**3. 对比多篇文献**
```
我有这几篇文献的要点：【粘贴或上传】，请帮我做一个对比表：方向、方法、数据、结论、差异点。
```

**4. 从文献提取结构化数据（配合 Gemini 用）**
```
请从这篇论文中提取【化合物/数据】信息，整理成表格，列：名称、分子式、分子量、关键性质、来源页码。
```

## 二、处理数据

**5. 数据分析**
```
我有这份数据【上传 CSV/Excel】，请帮我：
1. 概述数据基本情况（行列数、缺失值、类型）
2. 做描述性统计
3. 分析【某个变量】的趋势
4. 生成可用的绘图代码
```

**6. 生成图表代码**
```
请用 Python + matplotlib/pandas 写一段代码，读取【数据描述】，绘制【图类型】，要求：坐标轴标签中文、配色美观、保存为 PNG。
```

## 三、学术写作

**7. 英文润色**
```
请把下面这段学术英文润色得更地道、更严谨，保持原意，适合期刊投稿。请保留专业术语准确。
【粘贴原文】
```

**8. 中文→英文翻译（学术）**
```
请把下面这段中文翻译成学术英文，语气正式，符合 SCI 论文风格。避免口语化。
【粘贴中文】
```

**9. 改写 / 降AI率**
```
请改写下面这段文字：保持原意，调整句式和语序，增加连接词，让表达更像人类写作。不要用"首先/其次/最后"这类套话。控制 AI 痕迹。
【粘贴原文】
```

**10. 写研究计划 / 开题**
```
请帮我写一份【主题】的研究计划/开题报告框架，包含：背景、研究问题、目标、方法、创新点、时间安排。突出可行性和创新性。
```

## 四、日常科研效率

**11. 会议纪要**
```
这是会议录音转写，请整理成纪要：参会事项、结论、待办（负责人+时间）。
【粘贴转写】
```

**12. 文献翻译**
```
请翻译这篇论文摘要成中文，保留术语准确，标注关键概念。
```

**13. PPT 大纲**
```
请根据下面的内容生成一个 10 页汇报 PPT 大纲，每页一个主题 + 要点，语言精炼。
【粘贴内容】
```

## 五、写作规范

**14. 参考文献格式化**
```
请把下面的参考文献按 GB/T 7714 格式规范化：【粘贴】。
```

**15. 检查论文逻辑**
```
请审阅下面这段：1) 逻辑是否连贯 2) 有没有重复或空话 3) 建议怎么改。逐条列出。
【粘贴正文】
```

---

## 提示词使用小技巧

1. **越具体越好**：给主题、给数据、给格式要求，AI 输出越准。
2. **分步提问**：先要框架，再要展开，别一次要太多。
3. **不满意就追问**："这部分再具体些""换个角度""给我 3 个版本"。
4. **关键引用要核对**：AI 生成的参考文献可能不真实，务必对照原文。
5. **隐私保护**：不把未发表数据、个人信息喂给在线 AI。
