# 07 常见问题

## 1. 哪些工具免费？

| 工具 | 是否免费 |
|------|---------|
| DeepSeek | 网页版免费，API 按量付费 |
| 豆包 / Kimi / 千问 | 免费 |
| 磐石 / 文献罗盘 | 用学校 edu 邮箱免费 |
| Zotero / Obsidian / Overleaf | 免费或学生免费 |
| ChatGPT / Claude / Gemini | 基础免费，进阶订阅 |
| NotebookLM | 免费 |

## 2. 一定要用 edu 邮箱吗？

- **磐石 / 文献罗盘**：需要（学校邮箱注册才有完整权限）。
- 其他工具普通邮箱即可。

## 3. 怎么省钱？

- **Codex 接 DeepSeek**：用 DeepSeek 低价 API，避免高价订阅。
- 日常任务用免费 DeepSeek / 豆包，贵的模型留给复杂任务。
- DeepSeek 2026 有峰谷定价（非高峰更便宜），可错峰调用。

## 4. 数据安全注意什么？

- **不要**把隐私数据（身份证、手机号、未发表论文）喂给在线 AI。
- 敏感材料用本地工具（如 VSCode + 本地模型），或脱敏后再用在线 AI。
- 公开代码前，检查是否含个人信息、密钥、内部信息。

## 5. 换模型麻烦吗？

- 网页版直接换标签即可。
- 代码 / 工具链（Codex / VSCode / Trae）：改 API 配置即可，一般 2-5 分钟。

## 6. AI 会瞎编参考文献吗？

- **会。** AI 生成的参考文献可能不真实。
- 对策：用 Zotero 管理真实文献；AI 生成后务必核对原文；关键引用从数据库（TCMSP / Web of Science / CNKI）获取。

## 7. 写论文用 AI 会被查重/降AI率吗？

- 各平台检测方法不同。
- 建议：AI 辅助写作后，用自己的话重写、调整结构、补充真实数据，不要直接提交 AI 原文。
- 部分期刊要求披露 AI 使用情况，投稿前先确认目标期刊政策。

## 8. 我的设备够用吗？

- **普通写作/问答**：手机或普通电脑即可，全部网页版。
- **处理数据/跑代码**：普通电脑装 Python / VSCode 即可。
- **大模型训练/大规模仿真**：需要服务器或云算力（如国家超算互联网、学校集群）。

## 9. 有哪些免费的科研资源平台？

| 资源 | 用途 | 获取 |
|------|------|------|
| 学校图书馆 | Web of Science / CNKI / Scopus | 校园网 |
| 国家超算互联网 | 免费算力 / 限时模型 | `scnet.cn` |
| arXiv | 预印本论文 | arxiv.org |
| GitHub | 开源代码 / 数据集 | github.com |
| 中科院文献服务 | 文献检索 | 学校合作渠道 |
