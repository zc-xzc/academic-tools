## 注册小贴士

1. **优先用学校 edu 邮箱**：磐石、文献罗盘、北大法宝都需要，其他工具普通邮箱即可。
2. **需要国际网络的工具**：ChatGPT、Claude、Gemini、NotebookLM——没有条件时可先用 DeepSeek/豆包/Kimi 替代。
3. **费用优先级**：DeepSeek + 磐石（edu）+ Zotero + Obsidian + Python 全免费，能覆盖大部分科研场景。
4. **API 省钱**：Codex / VSCode / Trae 均可接 DeepSeek API，避免高价订阅。
