# 视频抽帧工具

一个带 GUI 的视频帧提取工具，支持单视频 / 文件夹批量处理，支持时间范围截取、JPEG/PNG 输出、画质调节和分辨率缩放。

## 版本

| 文件 | 版本 | 说明 |
|------|------|------|
| `video_frame_extractor.py` | **V3** | 当前最新版，含全部功能 |
| `video_frame_extractor_v1_full.py` | V1 | 原始版本，仅全视频抽帧 |

## 功能

- [x] 单视频 / 文件夹批量模式切换
- [x] 自定义每秒抽取帧数（1-60）
- [x] 时间范围截取（从 X 秒到 Y 秒，留空=全部）
- [x] JPEG / PNG 输出格式可选
- [x] 画质滑块（1-100）
- [x] 分辨率缩放（原尺寸 / 50% / 25% / 自定义宽度）
- [x] 文件夹批量模式自动添加父文件夹前缀
- [x] 中文路径完整兼容（Windows 8.3 短路径 + Python 原生 IO）
- [x] 深色主题
- [x] 多线程后台处理，界面不卡顿
- [x] 进度条实时显示

## 环境要求

- Python 3.12+
- opencv-python (`pip install opencv-python`)
- tkinter（Python 内置）

## 启动

```powershell
python video_frame_extractor.py
```

## 使用说明

1. 顶部切换 **单视频** 或 **文件夹批量** 模式
2. 点击 **浏览** 选择视频文件或文件夹
3. 设置 **每秒抽取帧数**（如 1 = 每秒 1 张）
4. 可选：填写 **时间范围**（如从 10 秒到 60 秒）
5. 底部选择 **输出格式**、**画质**、**缩放**
6. 点击 **开始抽帧**
7. 完成后弹窗询问是否打开输出目录

## 输出

每个视频生成独立文件夹 `{视频名}_frames/`，图片命名：
```
frame_00001_0.00s.jpg
frame_00002_1.00s.jpg
...
```
文件夹批量模式勾选前缀后：
```
{文件夹名}_{视频名}_frame_00001_0.00s.jpg
```
